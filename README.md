### AI Stock Market Predictor

A stock-price prediction learning project started during the Harvard AI bootcamp in Google Colab. The available code converts arrays to tensors, trains a time-series model using mini-batches and backpropagation, generates test predictions, and reverses target scaling.

[Explore the project](stock-market-predictor/README.md) · [View the code excerpt](stock-market-predictor/training_excerpt.py) · [Source and attribution](stock-market-predictor/SOURCE.md)
